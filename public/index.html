Prøv:
Om datagrunnlaget og beregningen

1. Publisert klinisk evidens

Pasientrapporter er grunnlaget, også én rapport. Opplysninger via Trinidad er merket når kasuset ikke er separat kontrollert. Kjente feil og konflikter beholdes som varsler.

2. Avledet allelklasse

Severe eller Moderate kan avledes fra klinisk evidens. Det er ikke det samme som observert fenotype. Pseudodefisiens og ikke-kausale kontrollvarianter skilles ut.

3. Betinget matrisesvar

Arbeidsregelen er Severe + Severe = infantil/sen-infantil, Moderate + Severe = juvenil og Moderate + Moderate = voksen. Benign + enhver klasse gir asymptomatisk i regelen.

4. Målinger og modellskårer

Enzymaktivitet fra laboratoriekonstrukt og skårer fra prediktorverktøy vises separat fra den klinisk avledede allelklassen.

Antall rapporter

Antall er rapport-/tabellrader, ikke bekreftet unike pasienter. Mulige dubletter er ikke ferdig avklart.
